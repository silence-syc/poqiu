# 破囚战队 · CRTC2026 参赛文档仓库

本仓库用于存放 **破囚战队** 参加重庆大学机器人训练大赛 CRTC2026（资源争夺赛）的备赛文档。

## 文档结构

```
docs/
├── 00-总体设计与开发日志.md            # 总体篇：赛题理解、系统架构、时间线、规范自检
├── 01-机械组日志.md                    # 机械组：底盘、机械臂、夹爪、结构
├── 02-电控组日志.md                    # 电控组：主控、驱动、供电、遥控
├── 03-视觉组日志.md                    # 视觉组：硬件链路、识别、供电
└── images/                             # 文档配图
    ├── mech_grab_01.jpg
    ├── mech_grab_02.jpg
    └── mech_grab_03.jpg
    └── ......
```

## 文档组织方式

采用「**总体 + 分组**」双层次结构：

| 层级 | 内容 | 作用 |
|---|---|---|
| **总体篇** | 赛题理解、系统架构、时间线、规范自检、问题反思 | 展示团队对赛题的整体把握与工程组织能力 |
| **分组篇** | 机械组 / 电控组 / 视觉组各自的技术实现 | 深入展示各模块的技术细节与实现过程 |

每个分组文档均包含：

- **组内职责与接口**：该组负责什么、与其他组如何对接；
- **技术选型对比**：为什么选这个方案（如高低底盘、钩爪 vs 夹爪、按键 vs 摇杆）；
- **实现细节**：关键代码 / 电路 / 结构的思路；
- **问题与解决**：真实遇到的难点与处理方式；
- **图片佐证**：实拍 / 测试截图。
